Identificador único atribuído pelo sistema operacional a cada processo em execução.

Kernel

Núcleo do sistema operacional responsável por gerenciar hardware, memória e processos.

Área de memória dinâmica utilizada pelo processo Node.js para armazenar objetos.

Container

Ambiente isolado que compartilha o kernel do host e possui limites próprios de recursos.
